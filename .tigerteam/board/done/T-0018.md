## Required changes
1. **"never reach the guest" is false** (T-0013 N2). Both man pages
   (`man/remote-viewer.pod` ~107-110, `man/virt-viewer.pod` ~126-129) and
   `docs/macos.md` (~474-475) say hotkeys using the Command key "never
   reach the guest". The Send key menu can synthesize exactly those
   combinations in the guest. In all three places, replace that clause
   with: "the Command key itself is consumed by the host when pressed as
   part of a hotkey; the I<Send key> menu can still synthesize
   Command-based combinations in the guest." (Use `*Send key*` styling in
   the .md file; keep POD markup valid in the .pod files.)
2. **Dead symbol reference** (T-0013 N3). `docs/macos.md` ~481 points at
   `virt_viewer_window_send_keys()`, which does not exist. Point at
   `virt_viewer_window_action_send_key()` (src/virt-viewer-window.c) and
   `virt_viewer_display_send_keys()` (src/virt-viewer-display.c).
3. **CI caveat** (T-0013 N14). In the `docs/macos.md` "Continuous
   integration" section (~231-236), add one sentence: the workflow runs
   only on GitHub-hosted mirrors and forks; upstream's GitLab CI has no
   macOS runners and does not execute it.
4. **Formula retarget** (T-0013 B2 / T-0012 B4). In
   `build-aux/macos/virt-viewer.rb`, change the `head` source from
   `https://github.com/ubyjvovk/virt-viewer.git`, branch `mac-port`, to
   `head "https://gitlab.com/virt-viewer/virt-viewer.git"` (default
   branch, no `branch:` argument). Update the `docs/macos.md` formula
   section (~187-195) to match: it is a head-only formula that builds the
   upstream default branch, and it only produces a macOS-capable build
   once this port is merged there; until then, users should brew from a
   fork or tap carrying the port.
5. **LSHandlerRank note** (T-0014 NB3; the plist edit itself is T-0016's).
   In the `docs/macos.md` URL-handlers section, add one sentence: the
   `spice` scheme is declared `LSHandlerRank` `Owner` (virt-viewer defines
   that scheme's UX); `vnc` is deliberately rank-free so Remote Viewer
   never steals the default from a user's chosen VNC client.

## Goal
A GitHub Actions workflow that builds and tests the tree on `macos-latest`
with Homebrew dependencies on every push and pull request, so the macOS port
cannot silently regress.

## Context
- Upstream CI is GitLab (`ci/`, `.gitlab-ci.yml`) and has no macOS runners;
  do not touch those files.
- The build entry point is `bash build-aux/macos/check.sh` (configures
  `build/`, compiles, runs `meson test`). Use it verbatim in the workflow.
- Brew packages to install in CI: meson ninja pkgconf gtk+3 gtk-vnc
  spice-gtk spice-protocol libvirt libvirt-glib vte3 libxml2 gettext
  adwaita-icon-theme gtk-mac-integration dylibbundler.
- Use `actions/checkout@v4` with `fetch-depth: 0` (the build uses git to
  generate AUTHORS). Use `HOMEBREW_NO_INSTALL_CLEANUP=1` and
  `HOMEBREW_NO_AUTO_UPDATE=1` to keep the job fast.
- Upload `build/meson-logs/` as an artifact with `if: always()`.
- If a `build/*.app` exists after the build (later tickets add a bundle step),
  upload it too; guard with `if: hashFiles('build/*.app/Contents/Info.plist') != ''`
  — the workflow must be valid today when no bundle is produced.

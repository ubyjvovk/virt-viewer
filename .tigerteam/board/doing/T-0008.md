## Goal
Two distribution helpers: a Homebrew formula (`head` build from this
repository, usable as a local tap) and a script that wraps
`Remote Viewer.app` into a compressed DMG.

## Context
- Formula: `build-aux/macos/virt-viewer.rb`, class `VirtViewer`, `head`
  pointing at the repository's git URL with `branch: "mac-port"` (read the
  URL from `git remote get-url origin`), depends_on for the brew packages
  listed in `docs/macos.md`, `def install` = `system "meson", "setup",
  "build", *std_meson_args` / `ninja -C build` / `ninja -C build install`,
  and a `test do` running `remote-viewer --version`. Validate with
  `brew audit --formula build-aux/macos/virt-viewer.rb` if it runs offline;
  otherwise `ruby -c`.
- DMG: `build-aux/macos/make-dmg.sh` (bash, `set -euo pipefail`) uses
  `hdiutil create -volname "Remote Viewer" -srcfolder <staging> -ov -format UDZO
  <out.dmg>` where staging contains the app and an `Applications` symlink.
  Default input `build/Remote Viewer.app`, output `build/RemoteViewer-<version>.dmg`.
- `docs/macos.md`: "Distribution" section documenting both.

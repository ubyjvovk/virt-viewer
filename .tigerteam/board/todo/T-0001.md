## Goal
Document how to build, test and run virt-viewer/remote-viewer natively on
macOS with Homebrew, and make the top-level meson.build explicitly aware of
darwin where it currently only lists linux/freebsd/windows.

## Context
- The tree already builds and passes `meson test` on macOS (Apple clang,
  Homebrew GTK3). Confirm with `bash .tigerteam/scripts/run-tests.sh`.
- `build-aux/macos/check.sh` exists (PM-written): configure+compile+test.
  Read it; document it; add a header comment if it lacks anything.
- `meson.build` ~line 340: the `-fstack-protector-strong` block only applies
  to `linux`/`freebsd`/`windows`. Add `'darwin'` to that list (clang on
  macOS supports it; the aarch64 guard above it stays as-is).
- Homebrew formula names actually used on this host: meson ninja pkgconf
  gtk+3 gtk-vnc spice-gtk spice-protocol libvirt libvirt-glib vte3 libxml2
  gettext adwaita-icon-theme gtk-mac-integration dylibbundler.
- `libxml2` is keg-only: `PKG_CONFIG_PATH` needs
  `$(brew --prefix)/opt/libxml2/lib/pkgconfig` (check.sh already does this).
- Features unavailable on macOS: oVirt (`govirt-1.0`, `rest-1.0`) and
  bash-completion. They auto-disable; say so in the doc.

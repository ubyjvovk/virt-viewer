## Goal
Support SPICE server (relative) mouse mode: when the guest switches to
relative mode, grab the pointer, feed motion deltas via
`spice_inputs_channel_motion()`, and release the grab with a hotkey.
Today relative mode is logged and ignored (T-0022 gap list, ~250 LoC).

## Context
- Read `macos-native/README.md`; prior reports in `.tigerteam/board/done/`.
- API reference: spice-gtk 0.42 source (path in T-0023's Context) —
  `SpiceMainChannel` `main-mouse-update` signal / `mouse-mode` property;
  `spice-widget.c` implements exactly this grab dance for GTK; check
  whether the client can REQUEST a mode
  (`spice_main_channel_request_mouse_mode` or its deprecated alias in
  0.42) — you will need it for testing.
- Locked decisions (PM):
  - Mouse-mode plumbing: new callback `mouse_mode(void *user, int
    relative)` on `VsmSpiceCallbacks` (main-thread, like the rest); new
    `void vsm_spice_send_motion(VsmSpice *self, int dx, int dy, int
    button_state)` for deltas.
  - Grab = clicking the view while in relative mode (and automatically on
    mode switch if the window is key):
    `CGAssociateMouseAndMouseCursorPosition(false)`, hide the local
    cursor over the view (transparent-cursor mechanism from T-0023),
    use `NSEvent.deltaX/.deltaY` from mouse-moved/dragged events,
    periodically warp the hardware pointer back to the view centre
    (`CGWarpMouseCursorPosition`) so it never hits the screen edge.
  - Ungrab hotkey: **⌃⌥ (Control+Option) pressed together and released** —
    same as virt-viewer's default. Also ungrab on window resign-key and
    app deactivate. While grabbed, append " (press ⌃⌥ to release)" to
    the window title (v-v convention); restore the title on ungrab.
    The ⌃⌥ chord used for ungrab must NOT leak a stuck modifier to the
    guest (release-all or suppress those synthetic modifier events).
  - Re-associate the cursor (`CGAssociateMouseAndMouseCursorPosition(true)`)
    on ungrab, disconnect, quit, and every error path — a wedged pointer
    on the user's machine is the failure mode to fear most; structure the
    code so there is ONE ungrab function and every exit calls it.
  - In absolute mode nothing changes.
- Testing against `spice://100.101.77.113:5900` (disposable, benign input
  only): the guest normally runs absolute (tablet) mode. Use the client
  mode request found above to force server mode for the test run
  (a debug env var like `VSM_FORCE_RELATIVE=1` MAY be committed if inert
  by default and documented). Evidence: trace shows `motion dx,dy`
  streams while grabbed; guest cursor visibly moves (screenshot before /
  after a scripted or manual drag); ungrab restores the local pointer.
- Engine ceiling ≈45 min: commit early and often; hand off INCOMPLETE
  with precise next steps. If the mode request API turns out not to
  exist in 0.42, STOP and block with `## Questions` (do not build a
  server-side workaround).

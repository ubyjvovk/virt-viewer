## Goal
A double-clickable, relocatable `.app` for the native viewer: bundle
script, Info.plist with `spice://` URL scheme and `.vv` document type,
Cocoa handlers that route both into the existing connect path, ad-hoc
codesigning that survives Gatekeeper's code-signature kill.

## Context
- Read `macos-native/README.md`; prior reports in `.tigerteam/board/done/`.
- **Study the GTK port's bundler first**: `build-aux/macos/make-bundle.sh`
  solved the hard problems already — recursive dylib copy +
  `install_name_tool` rewrite, LC_RPATH dedupe, and the critical lesson
  (T-0006): **every bundled Mach-O must be codesigned AFTER the last
  install_name_tool rewrite**, or dlopen dies with SIGKILL (Code
  Signature Invalid) and the app "quits unexpectedly". This app is far
  simpler (no GTK, no pixbuf/IM caches, no GStreamer) — do NOT copy the
  cache machinery, only the dylib+sign pattern.
- Locked decisions (PM):
  - New script `macos-native/make-bundle.sh` (bash, `set -euo pipefail`,
    runs from any cwd) building `macos-native/build/SPICE Viewer.app`.
    The display name lives in ONE variable at the top (`APP_NAME="SPICE
    Viewer"`) — it is a placeholder pending a user decision; note that in
    a comment.
  - Info.plist: `CFBundleIdentifier` `io.github.virt-viewer.spice-viewer`
    (placeholder, single variable), `NSHighResolutionCapable` true,
    `LSMinimumSystemVersion` matching what the binary is actually built
    for (check `vtool -show-build` / minos — the GTK port shipped a 12.0
    plist over 26.0 binaries, review finding opus B3; do not repeat it),
    `CFBundleURLTypes` for `spice` and `spice+tls`,
    `CFBundleDocumentTypes` for the `vv` extension.
  - App delegate: `application:openURLs:` and `application:openFile:` →
    if no session is connected, connect (same path as the connect
    window); if a session IS connected, show a one-button alert "Already
    connected — disconnect first" and ignore. Handlers must work both at
    launch (Finder starts the app) and while running.
  - `.vv` parsing: `GKeyFile`, group `[virt-viewer]`, honor `type`
    (must be `spice`, else error alert), `host`, `port`, `password`;
    log-and-ignore all other keys (each ignored key g_message'd once).
    Delete-on-open (`delete-this-file=1`) is honored.
  - The plain binary build (`build.sh` → `spice-viewer`) must keep
    working; make-bundle.sh may call build.sh.
- Test target `spice://100.101.77.113:5900` (disposable, benign input
  only, never hardcode the URI in committed files).
- Verification is Finder/LaunchServices-level: use `open` (the bundle,
  the URL, a .vv file), give it seconds, then check
  `~/Library/Logs/DiagnosticReports` for new crash logs (there must be
  none). Record PIDs and `kill` exact PIDs — never `pkill -f`.
- Engine ceiling ≈45 min: commit early and often; hand off INCOMPLETE
  with precise next steps.
